## Project Overview

This repository contains the research work conducted during the first year of my PhD thesis on forest management at landscape scale. The work focuses on multi-scale forest dynamics analysis using ForCEEPS simulations and forest inventory data from the Retz forest.

## Repository Structure

### `Phd_subject.pdf`
Official thesis subject document defining the research scope, objectives, and institutional framework for the forest management at landscape scale project.

### `Code/`
Complete R codebase containing analysis workflows, utility functions, and visualization scripts. Includes inventory testing, multi-scenario simulations, parameter sensitivity analysis.

### `Redaction/`
Thesis writing and documentation materials including draft chapters, literature reviews and a big introduction to forest management concepts (in Position Paper)

### `Forceeps_data.zip`
Archived ForCEEPS simulation data including input files (inventories, site parameters, climate data) and processed output datasets from all analysis workflows. NEED TO ASK FOR THEM (to heavy to upload on github)

### `ONF_data_RETZ_FIF.zip`
Raw forest inventory data from the Office National des Forêts (ONF) for the Retz forest, including stand characteristics, species composition, and spatial information used as the foundation for simulations. NEED TO ASK FOR THEM (to heavy to upload on github)
